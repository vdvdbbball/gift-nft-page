# Telegram Gift & NFT Shop

Повноцінний Telegram-магазин для продажу Telegram Stars, NFT-подарунків та інших цифрових товарів.

## Основні можливості

- 🤖 Telegram Bot з українською локалізацією
- 🛒 Веб-сайт каталогу товарів
- 🔐 Адмін-панель з авторизацією
- 💰 Підтримка платежів (TON Wallet, Telegram Stars)
- 📊 Статистика продажів
- 🎨 Темний дизайн у стилі Telegram
- 📱 Адаптивний дизайн для всіх пристроїв

## Структура проєкту

```
├── backend/              # Node.js/Express сервер
├── frontend/             # Веб-сайт
├── admin/                # Адмін-панель
├── telegram_bot/         # Telegram Bot
├── database/             # SQL схеми та міграції
└── config/               # Конфігурацій файли
```

## Встановлення і запуск

Детальні інструкції див. у розділі нижче.
